# Developer Portfolio

A clean, modern, and responsive developer portfolio website built with Next.js, Tailwind CSS, and Framer Motion. 

This project features a dynamic animated background, full-screen seamless transitions, and a fully data-driven content architecture. It is designed to be easily scalable and maintainable.

## Documentation

Comprehensive documentation can be found in the `docs/` directory:

- [Implementation Plan](docs/implementation_plan.md): The original architectural plan and design decisions.
- [Development Guide](docs/DEVELOPMENT.md): Instructions for setting up the local development environment and understanding the codebase architecture.
- [Usage Guide](docs/USAGE.md): Instructions on how to manage and update the portfolio content without writing code.
- [Contributing Guidelines](CONTRIBUTING.md): Guidelines for contributing to the project.

## Tech Stack

- **Framework**: Next.js (App Router)
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Theming**: `next-themes` (Light/Dark mode)

## Deployment

This project is optimized for deployment on [Vercel](https://vercel.com).
