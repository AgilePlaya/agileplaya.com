# Contributing Guidelines

Thank you for your interest in contributing to this developer portfolio project!

## How to Contribute

1. **Fork the Repository**: Start by forking the repository to your own GitHub account.
2. **Clone the Repository**: Clone your fork locally.
3. **Create a Branch**: Create a new branch for your feature or bug fix (`git checkout -b feature/your-feature-name`).
4. **Make Changes**: Implement your changes. See [DEVELOPMENT.md](docs/DEVELOPMENT.md) for architectural details.
5. **Test Your Changes**: Manually verify your changes on both desktop and mobile views. Ensure the Light/Dark theme still functions correctly and no scrolling is introduced on the desktop view.
6. **Commit Your Changes**: Commit your changes with clear, descriptive commit messages.
7. **Push to Your Fork**: Push your branch to your forked repository.
8. **Submit a Pull Request**: Open a pull request against the `main` branch of the original repository.

## Reporting Issues

If you find a bug or have a feature request, please open an issue on the GitHub repository. Provide as much detail as possible, including steps to reproduce bugs.

## Style Guide

- Follow the existing code style and structure.
- Use Tailwind CSS for all styling.
- Keep components small and focused.
- Ensure any new textual content can be driven by the JSON data files in `/src/data`.
